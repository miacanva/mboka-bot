# MBOKA TECH BOT - WhatsApp Bot

## Features
- ✅ Auto View Status
- ✅ Auto React to Status
- ✅ Always Online
- ✅ Anti-Delete Messages
- ✅ Auto Read Messages
- ✅ Custom Commands

## Deployment on Katabump

1. Upload all files to your GitHub repository
2. On Katabump panel, connect your GitHub repo
3. Set start command: `npm start`
4. Deploy the bot
5. Enter your phone number when prompted
6. Scan the QR code with WhatsApp

## Commands
- `.menu` - Show all commands
- `.ping` - Check bot status
- `.owner` - Bot owner info
- `.time` - Current time
- `.stats` - Bot statistics (owner only)
- `.restart` - Restart bot (owner only)

## Owner Only
Replace the owner number in config.js or enter when prompted
